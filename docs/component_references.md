# Component References

This page lists **safe, legal, educational** components that can be used to study an aerospace software stack.

## Flight computer and avionics

- **Microcontroller:** Arduino-class or STM32-class development board
- **IMU:** 6-axis or 9-axis inertial sensor module
- **Barometer:** environmental pressure sensor module
- **GPS:** standard GPS receiver module
- **Storage:** microSD logging module
- **Radio:** low-power telemetry radio module where legal

## Supporting electronics

- regulated battery pack
- voltage monitoring circuit
- indicator LEDs
- level shifting where needed
- breadboard or prototyping PCB for demonstrations

## Mechanical references

- generic airframe tube
- nose cone reference model
- fin geometry reference
- payload bay enclosure concept
- recovery bay enclosure concept

## Safe usage principles

- use only certified, legal educational components
- follow vendor documentation
- keep the build focused on sensing, logging, and analysis
- do not improvise hazardous propulsion or ignition systems

## Recommended documentation images

Use clear, labeled photos of:
- a development board
