# Mission Statement

## Project Goal

Build a research-grade educational aerospace platform that can:
- estimate flight state from noisy sensor data
- detect anomalous behavior in real time
- log mission telemetry in a structured format
- replay and analyze missions after flight
- validate simulation against observed behavior

## Research Question

How can an educational launch vehicle be made more observable, explainable, and analytically useful through sensor fusion, telemetry, and anomaly-aware flight logic?

## Why this is original

Many aerospace education projects focus only on build instructions or simple physics demonstrations. This project focuses on the engineering system around the vehicle:
- data pipeline
- flight state estimation
- anomaly classification
- post-flight analysis
- simulation consistency

## Outcome

A professional, portfolio-ready aerospace software platform that demonstrates systems thinking, autonomy, and real-world engineering rigor.
