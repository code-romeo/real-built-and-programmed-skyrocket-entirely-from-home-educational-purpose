# Visual Gallery

This gallery is intended for **safe educational reference** only.

## What belongs here

- labeled diagrams of avionics modules
- simulation screenshots
- telemetry dashboard views
- public-domain or manufacturer-provided images of benign rocketry components

## What does not belong here

- teardown images that enable unsafe build steps
- ignition or propellant handling imagery
- dangerous assembly instructions
- any content that would facilitate weaponization or unsafe propulsion

## Caption style

Each image should include:
- component name
- purpose
- safe educational context
- source attribution if required

## Example captions

- **Avionics Stack** — educational architecture for sensor fusion and telemetry logging.
- **Mission Dashboard** — sample plots used for post-flight analysis.
- **Telemetry Flow** — data pipeline from sensors to logger to replay tool.
